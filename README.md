# 최다은 | 게임 사운드 디자인 포트폴리오

공개 주소 https://sarahcheh.github.io/

첫 작품은 상단에 크게 표시합니다. 나머지 작품은 그 아래에 배치합니다.
영상은 페이지 안에서 재생하며, 작업 설명은 접힌 상태에서 열어볼 수 있습니다.
다른 작품 구간에서 상단의 작품 목록을 펼치면 7개 작품으로 이동할 수 있습니다.

## 파일 구성

- index.html — 작품 순서와 설명
- content.js — 작품별 영상 주소
- script.js — 영상 재생과 작품 탐색
- styles.css — 화면 구성과 반응형 스타일
- assets/ — 작품 그래픽과 파비콘

GitHub Pages는 main 브랜치의 루트에서 배포합니다. 설치나 빌드 없이 이 폴더를 사용할 수 있습니다.
로컬 미리보기와 공개 사이트의 YouTube 재생 환경은 다를 수 있습니다.
검색 제외를 요청하는 noindex, nofollow 메타 태그를 사용합니다.
