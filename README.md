# 최다은 | 게임 사운드 디자인 포트폴리오

공개 주소 https://sarahcheh.github.io/

첫 작품은 상단에 크게 표시합니다. 나머지 작품은 그 아래에 배치합니다.
영상은 페이지 안에서 재생하며, 작업 설명은 접힌 상태에서 열어볼 수 있습니다.
다른 작품 구간에서 상단의 작품 목록을 펼치면 7개 작품으로 이동할 수 있습니다.

## 파일 구성

- index.html — 작품 순서와 설명
- content.js — 작품별 영상 주소
- script.js — 영상 재생과 작품 탐색
- styles.css — 화면 구성과 반응형 스타일
- assets/ — 작품 그래픽과 파비콘

GitHub Pages는 main 브랜치의 루트에서 배포합니다. 설치나 빌드 없이 이 폴더를 사용할 수 있습니다.
로컬 미리보기와 공개 사이트의 YouTube 재생 환경은 다를 수 있습니다.
검색 제외를 요청하는 noindex, nofollow 메타 태그를 사용합니다.

## 언어

상단 한국어 / English 버튼으로 전환합니다. 처음 방문하면 한국어로 표시하며, 선택한 언어는 해당 브라우저에 기억합니다.
?lang=en 주소로 영어 화면을 바로 열 수 있습니다.
작품 본문 번역은 locales.js에서 관리합니다.

## 사이트 관리

왼쪽 상단 음파 아이콘을 55px 이상 드래그하거나, Alt + Shift + M을 누르면 인증 창이 열립니다.
입구는 탐색 편의 기능이며, 저장 권한은 GitHub 인증으로 확인합니다.

GitHub에서 이 저장소만 선택한 Fine-grained personal access token을 발급합니다.
Repository permissions의 Contents를 Read and write로 설정하고 만료일을 지정합니다.
인증 창에 접근 키를 입력하면 작품 순서와 한국어·영어 소개를 수정할 수 있습니다.
첫 번째 작품이 상단 큰 영상으로 표시됩니다.

변경 내용은 site-settings.json 한 파일에 저장됩니다.
다른 곳에서 먼저 변경한 내용이 있으면 덮어쓰기를 차단합니다.
접근 키는 창을 닫거나 15분이 지나면 지워집니다. 브라우저 저장소나 저장소 파일에 기록하지 않습니다.
로컬 미리보기에서는 기본 설정을 사용하며, 사이트 저장은 공개 사이트에서 사용하는 것을 권장합니다.
방문자 집계는 연결하지 않았습니다.
